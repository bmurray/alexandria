# Valsoft Agentic Coding Challenge

## Library Management System

You can build this with Cursor, Windsurf, GitHub Copilot or any agentic
coding assistant of your choice.

### Minimum Features

-   **Book Management**: Add, edit, and delete books (title, author +
    whatever metadata you see fit).

-   **Check-in/Check-out**: Mark books as checked in (borrowed) or
    checked out (returned)

-   **Search**: Find books by title, author, or other fields.

### Requirements

-   Complete a **working product** using any language, framework, or
    development tool (including AI tools).

-   Provide your source code on **GitHub** and a **README** explaining
    how to run it.

### Bonus

-   **Deploy** the app and provide a URL for live testing.

-   Add an authentication system with SSO, preferably with different
    user roles and permissions.

-   Implement any **AI features** you can think of.

-   Add extra features as you see fit, to **demonstrate your
    creativity**.

### Evaluation Criteria

-   **Completeness**: Does the product work and cover the core features?

-   **Creativity**: Are extra features and creative ideas incorporated?

-   **Product Quality**: Is the product clean and organized?

-   **Usability**: Is the app intuitive
